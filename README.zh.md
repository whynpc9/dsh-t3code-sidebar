# dsh-t3code-sidebar

[English](README.md) | 中文

为 DeepSeek Harness 提供 T3 Code 风格的任务侧栏：保留原生 Workspaces 的构图与操作，把会话按任务状态整理，也可按工作区或单列表查看。

> 当前为 **v0.1.0 稳定版**。已验证 Linux Web + `@deepseek-ai/dsh` `0.2.2-rc.1`。macOS Desktop 仅部分验证，原定低峰边界投递和一次退出卡住仍待调查。Windows 尚未验证。详见[支持矩阵与已知限制](docs/release.zh.md)。

## 功能

- **三种分组**：按状态（默认）、按工作区、单列表；支持搜索和归档筛选。
- **任务分区**：置顶、待处理、稍后处理、已处理；空分区自动隐藏。可选的**运行中**分区（默认关闭）会把运行中的会话从“待处理”中收起，需要你处理时它们会回到“待处理”。
- **低峰时段选择**：用“至低峰时段”隐藏会话，或显式选择“低峰时段继续…”，让 Harness 在半价低峰时段开始时向已知空闲的会话发送一条可编辑消息。低峰操作默认开启。
- **任务整理**：稍后处理、手动收起、结果确认，以及默认 7 天无活动自动收起。
- **灵活策略**：自动收起可关闭或改为 1–90 天，支持工作区覆盖和单会话豁免。
- **原生体验**：会话菜单、工作区管理、中英文、亮暗主题及窄栏跟随 Harness。

## 安装

建议先在测试 profile 中安装稳定版 v0.1.0：

```sh
dsh plugin --profile <profile> add dsh-t3code-sidebar@0.1.0
dsh --profile <profile>
```

卸载后原生侧栏自动恢复，会话与聊天记录不受影响：

```sh
dsh plugin --profile <profile> remove dsh-t3code-sidebar
```

升级、回滚、本地 tarball 安装和 registry 验证见[发行说明](docs/release.zh.md)。

## 使用

- 在侧栏的**视图选项**中切换分组和归档筛选；macOS 可用 `⌘K` 搜索、`⌘O` 添加工作区。
- 在会话的 **… 菜单**中稍后处理、收起、确认结果或设置自动收起豁免；归档仍使用原生菜单。
- 在 **插件 → dsh-t3code-sidebar** 中管理“运行中”分区和“低峰时段稍后处理”、调整自动收起与工作区策略，并预览效果、查看最近变更。侧栏的**视图选项 → 侧栏设置…**可直达。

“稍后处理”和“已处理”只改变侧栏整理状态，不会停止任务、归档会话或删除内容。“低峰时段继续…”是需要你显式选择的例外：它会创建一个 Harness 定时任务来发送你的消息。状态默认由 Host 持久化；浏览器本地降级模式的生命周期限制见[已知限制](docs/release.zh.md#5-已知限制)。

### 低峰时段稍后处理与继续

**启用与时间表。** **插件 → dsh-t3code-sidebar → 侧栏 → 低峰时段稍后处理**默认开启，设置按浏览器保存。设置页会显示当前价格时段、换算到你所在时区的高峰时间，以及 [DeepSeek 价格说明](https://api-docs.deepseek.com/quick_start/pricing)链接。关闭后会隐藏两个低峰操作，但不会取消已经安排的自动继续。

内置高峰时间表为 **UTC 周一至周五 01:00–04:00、06:00–10:00**，中国法定节假日除外。节假日数据覆盖 2026–2027 年；其他年份在数据更新前按普通工作日处理。低峰选项仅在高峰时段出现。如果下一个低峰窗口不足 4 小时，“至较长的低峰时段”和相应的自动继续选项会选择之后首个至少 4 小时的低峰窗口。

**“至低峰时段”仅改变显示。** 对未在运行工作的会话，打开 **… → 稍后处理 → 至低峰时段**。会话行显示“… 进入低峰时段”，到点后回到“待处理”。它不会发送消息、创建自动化任务或暂停 agent。普通稍后处理的限制仍然适用，例如需先取消置顶并处理待审批请求。

**“低峰时段继续…”会额外安排消息。** 只有 Host 所有者可以使用，并且需要 Host 后端和 Harness 定时任务服务可用；会话必须已知完全空闲：没有运行中的轮次、子代理、后台任务或其他定时工作，也没有待回答的问题或待审批请求。浏览器本地降级模式不提供此选项。

在对话框中选择低峰边界并编辑非空消息；中文默认为**继续。**（英文为 **Continue.**）。点击“确定”后会隐藏会话，会话行显示“… 自动继续”，并创建一个名为 **Off-peak resume** 的一次性任务，可在 Harness 的“自动化任务”中查看。到达边界时，由 Harness 而不是侧栏投递消息，让 agent 继续运行。

**取消与停机。** 投递前选择“立即返回并取消自动继续”，会让会话回到“待处理”并取消定时消息；“标为已处理”也会取消。自己发送消息，或新问题、新审批、新失败使稍后处理提前结束，也会取消。若只想取消 Harness 消息，也可以直接在“自动化任务”中删除任务。取消采用有限重试的尽力而为机制。

投递时 Host 必须运行。如果 Host 在边界时停机，Harness 会在重启后投递过期消息，此时可能已经进入后续高峰时段；插件不会把消息改到下一个低峰时段。迟延投递和取消的限制详见[已知限制](docs/release.zh.md#5-已知限制)。

## 开发

```sh
pnpm install --frozen-lockfile
pnpm run verify  # 类型检查、测试、构建、npm 包检查
pnpm pack
```

- `src/domain/`：状态、排序、时间和命令纯函数
- `src/contracts/`：共享 schema 与 Remote 契约
- `src/host/`：持久化、事件处理与调度
- `src/client/`：后端适配、视图模型和 React 界面
- `tests/`：单元、组件、集成与端到端测试

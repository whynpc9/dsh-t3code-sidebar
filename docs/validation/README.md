- [U07: Desktop keyboard and focus](u07/README.md): 2026-11-14, macOS Desktop; shortcuts, locating the current session, menu focus, and reduced motion.
- [A10: access control](a10/README.md): 2026-11-13, real Gateway and browser; guest denial, access revocation, and unknown fields.
- [Native layout validation](native-ui/README.md): 2026-11-12, Linux Web; native layout comparison, three layouts, search, settings, and screenshots.
- [M0 and alpha validation](poc/README.md): 2026-11-09 through 2026-11-12; feasibility, connectivity and lifecycle, early Desktop checks, and alpha.2 end-to-end records.

Screenshots and raw JSON data remain in their corresponding directories and are not included in the npm package.

## Q02 · 规模

在首次启动前，从已完成宿主轮次的日志生成 100 个工作区、每组 50 条会话。目录的 5001/5002 条记录包含宿主创建的空白会话。负载用真实 `session/prompt` 向 50 条不同会话并发提交测试提示。50 次都被接受，模型桩收到 50 次慢速请求，状态视图在开始主采样前和最后一次重载后均报告 Working 50。

| 指标 | 空闲 | 50 轮运行中 | 预算 |
| --- | ---: | ---: | ---: |
| 最近一项目录或基线到达至首屏 | 42–78 ms（6 次） | 94–101 ms（5 次负载下重载） | <300 ms |
| 标题或工作区搜索 p95 | 17 ms | 15 ms | <100 ms |
| 视图切换 p95 | 31 ms | 55 ms | <150 ms |
| 语义状态更新 p95 | 27 ms | 28 ms | <100 ms |
| 单列表常驻会话行峰值 | 56（至多可视 + 40） | 56（至多可视 + 40） | 可视 + 150 |

首屏从浏览器取得工作区、会话目录和插件基线中的最后一项开始计时。含页面加载的导航至首屏读数为 1.41–2.05 s。语义更新由另一标签页发出 Settle / Reopen，每组 20 次，测本标签页收到相应 follow delta 至会话移动后的动画帧，排除了命令的宿主往返。视图切换每组 30 次，搜索每组 20 次。

单列表取样滚动范围的 0%、25%、50%、75%、100%，再返回中间和顶部。键盘实测通过 End、定位当前会话、Home、ArrowDown。空闲时滚动前后 GC 后 JS 堆均为 32.6 MB；负载组滚动后为 33.7 MB，启用 50 个活动会话后的首次采样为 40.1 MB。5 次重载的 GC 后 JS 堆为 32.9–35.5 MB 和 34.7–36.9 MB。状态视图负载下 56 行，工作区视图默认折叠时为 6 条会话行和 100 个工作区标题。手动展开大量分组的情况未测。

## Q03 · 安装、冲突与启停

使用新建空 Web profile，从本地 tarball 安装先前的 alpha.1，再原地换成上述 alpha.2 候选包。alpha.1 由 `26b56f5` 构建，tarball SHA256 为 `154d060f6514300dd800ab2c3bd82353b9a8fa9024abf4af063b34adf6624cd7`。安装、升级、回退和卸载后刷新浏览器文档，Host 进程持续运行。20 次启停在同一标签页中执行，通过 Harness 的 `pluginManager/setBundleEnabled` 触发真实 Loader 热切换。

| 场景 | 结果 |
| --- | --- |
| 空 profile 安装、原地升级与回退 | 通过。alpha.1 中写入的 Snooze 状态、revision、原生会话在 alpha.2 和回退后的 alpha.1 中一致。 |
| 旧 revision 写入 | 通过。返回 `CONFLICT`，原先的 Snooze 和 revision 保留。 |
| 卸载、重装 | 通过。卸载后恢复原生侧栏，任务 Remote 不可用，会话仍在。重装恢复 Snooze。 |
| 同槽竞争 | 通过。priority -20 的测试插件接管该槽位，停用它后恢复候选包侧栏与 Snooze。 |
| 20 次 Loader 启停 | 功能通过。20 次停用均恢复单个原生侧栏，任务 DOM、样式和 follow 流均归零。20 次启用均恢复单个插件侧栏和一条 follow 流，每次核对原有 Snooze。 |
| Host 任务服务缺失 | 通过。用 `DSH_T3_SIDEBAR_HOST=off` 启动独立实例，任务 Remote 返回 404，客户端切到本地预览，本地 Snooze 在刷新后保留。 |

停用后的浏览器文档数、DOM 节点和事件监听器每次均为 2 / 1408 / 212。GC 后 JS 堆由 25.40 MB 升至 26.99 MB（+1.58 MB）。同一 Host 中保持侧栏停用，仅启停竞争夹具的 20 次对照由 26.25 MB 升至 26.70 MB（+0.45 MB）。两组顺序运行，且夹具没有加载任务客户端依赖。后续用堆快照和禁用 JIT 的对照复验定位增长来源，见下节。首次启停复跑在第 15 次启用后等不到 Host 侧栏，最终独立 profile 的完整复跑通过，超时未定位根因。

按本轮范围跳过实机断网重连和需要跨长时间段的场景，包括真实跨天自动 Settled。这里的结果覆盖 Linux Web，macOS Desktop 候选包复验仍归 M6。

### Q03 启停后的浏览器堆

沿用同一候选包。各组使用新开的 Chromium 页面，在 Loader 停用完成后强制 GC 采样。侧栏组渲染一条 Snooze 会话。竞争夹具遮挡组确认 Host follow 流在运行，但 `sidebar.workspaces` 始终由夹具占用。JIT 对照使用 V8 `--jitless`，仅用于验证增长来源。

| 场景 | 轮次 | 停用后 JS 堆变化 |
| --- | ---: | ---: |
| 侧栏启停 | 40 | 25.08 → 26.99 MB（+1.92 MB） |
| 只启停竞争夹具 | 40 | 23.35 → 24.07 MB（+0.71 MB） |
| 侧栏启停，界面由竞争夹具遮挡 | 40 | 23.29 → 25.08 MB（+1.79 MB） |
| 侧栏启停，禁用 JIT | 40 | 21.08 → 21.32 MB（+0.24 MB），第 5 至 40 次仅 +0.021 MB |
| 侧栏启停，独立页面复跑 | 100 | 24.76 → 27.10 MB（+2.34 MB），第 20 至 100 次 +0.60 MB |

40 次前后的最大堆快照增量是 V8 指令流和字节码，分别约 1.21 MB 和 0.25 MB。Blink 编译提示保留了约 0.46 MB 的侧栏脚本源码。源码只保留一份，第 20 至 100 次未观察到同类源码增量。停用后可找到同一个已释放后端的侧栏 Runtime，引用经过 Harness 槽位的 `rootInjectCache` 和 React 的条目回调。其后端为 `null`，通知计时器为 `undefined`。100 次复跑中，停用快照的侧栏 DOM、已断开的侧栏 DOM、`HostBackend` 实例和 `WakeDispatcher` 实例均为零，Runtime 数量始终为一。每次停用均核对 follow 流归零。

本轮增长主要来自 Chromium 的编译预热和脚本保留，测试范围内未发现侧栏对象按启停次数累积。第 20 至 100 次的总堆仍有小幅增长。原始读数和对象数量都保留在 [内存样本与引用链](heap-profile.json)。

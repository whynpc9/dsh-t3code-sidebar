# 原生构图侧栏 · 详细设计

版本：0.1 · 2026-11-12。本文取代[产品规格](product-spec.md)中关于侧栏**界面构图**的部分（双视图切换、工具栏、项目筛选、设置面板）；分区规则、Snooze/Settled 语义、时间策略、Host 存储与恢复不变，仍以产品规格、[实现 Spec](implementation-spec.md)、[时间策略 Spec](time-policy-spec.md) 为准。

## 1. 背景与目标

R0 alpha 的侧栏自带一套 UI：任务/项目分段切换、项目下拉筛选、正文搜索复选框、⚙ 设置面板、内联添加项目面板、“查看归档”链接、徽章式状态标签。元素多、未经统一设计，与 Harness 原生 `Workspaces` 区域的视觉语言不一致，用户需要重新学习。

原生区域设计成熟、用户熟悉，但它不提供可扩展的分组/排序/隐藏钩子（见 [调研](research/harness-plugin-boundary.md)），无法只“调”原生组件。因此本设计**继续占用 `sidebar.workspaces`，但按原生构图逐项复刻**，只在原生框架内加入任务能力：

1. 区域构图、尺寸、交互与原生一致：标题 + 可展开搜索 + 视图选项 + 添加工作区；32px 行；悬停卡片；行尾悬停操作。
2. 视图选项的“分组方式”新增 **状态**（Pinned/Active/Working/Snoozed/Settled），并设为默认。
3. 无条目的状态分区不显示。
4. 行尾悬停操作中原生的“归档”按钮替换为 **收起 / 取消收起**（Settle / Unsettle）；归档留在 “…” 菜单（原生会话菜单本就包含归档）。
5. 设置移出侧栏，放到 **插件** 页面中本插件的详情页。

## 2. 复用的宿主能力

| 能力 | 来源 | 用途 |
| --- | --- | --- |
| UI 原子：`StateDot`、`HoverCard`、`HoverCardGroup`、`Menu`、`Tooltip`、`Modal`、`Toast`、`Switch`、`Button`、`Input`、`relativeTime`、图标 | `@deepseek-ai/dsh-client-ui-primitives`（浏览器平台模块表，宿主共享实例） | 与原生相同的组件与动效，不打包副本 |
| 设计令牌：`--dsw-*`、`--dsh-sidebar-*` | 宿主样式 | 样式规则按**已发布的** `@deepseek-ai/dsh-client-ui-workspace@0.2.2-rc.1` CSS module 移植为 `t3sb-` 前缀类名（列表自身滚动、底部渐隐；调研固定提交更新，构图细节不同，不以其为准） |
| `useContextMenu().getTriggerProps`、`contextMenus.open/close/active` | ui-context-menu（全局标准 props 与服务） | 右键与 “…” 按钮打开的就是原生会话菜单（置顶、重命名、Fork、复制 ID、归档/取消归档，以及本插件的 Snooze/收起项）。“…” 按与已发布 0.2.2-rc.1 原生行相同的方式实现：带 `data-context-menu-trigger` 的按钮切换 `contextMenus.open/close`（较新上游提交中的 `contextMenu.button` 工厂在该版本中不存在） |
| `wide`、`expandSidebar` | `sidebar.workspaces` 槽位 owner props | 宽/窄栏；窄栏搜索先展开侧栏 |
| `plugins.bundle.config`（键为包名） | ui-plugin-manager | 插件详情页中的设置区 |
| `pluginNavigation.openBundle(pkg)`（可选服务） | ui-plugin-manager | 视图选项菜单中的“侧栏设置…”入口 |
| `uiWorkspace.pinSession/unpinSession/openSession/startSession/unarchiveSession/pickDirectory`、`workspaces.create/rename/delete`、`sessions.search` | 原生公共服务 | 行操作、工作区管理、搜索 |

渲染原生 `WorkspaceBrowser` 或其子槽位（行装饰、目录流）仍然不可行；这些点在第 9 节列为已知差异。

## 3. 区域构图

```
┌───────────────────────────────────────────┐
│ 会话                   [🔍] [⚙︎视图] [＋📁] │  标题行 36px：标题 · 搜索 · 视图选项 · 添加工作区
├───────────────────────────────────────────┤
│ 📌 置顶                                     │  分组行 32px（悬停：▸ 折叠箭头）
│   ●  修复登录回调                  5分钟     │  会话行 32px：状态点 · 标题 · 相对时间
│ ☰  待处理                                   │
│   ●  评审 PR #42                   待审批    │  待交互时以紧凑标签代替时间
│      重构存储层               … ✓ 📌        │  悬停：… 菜单 · 收起 · 置顶
│      展开其余 3 个会话                       │  原生水位线按钮
│ ⏰ 稍后处理  2                               │  折叠时显示数量
│ ✓  已处理  14                               │
└───────────────────────────────────────────┘
```

- **标题**：分组为“工作区”时显示“工作区”，否则显示“会话”（与原生一致）。
- **搜索**：放大镜按钮展开为输入框，标题与右侧按钮收起；Esc 或 ✕ 清空并收起；点区域外且无查询时收起。
- **视图选项**（滑杆图标，原生 `Menu`，dense，右对齐，portal）：
  - 分组方式：**状态**（默认）· 按工作区 · 单列表。
  - 筛选会话：隐藏已归档（默认）· 全部（显示已归档）· 仅显示已归档。
  - 分隔线后：**侧栏设置…**（仅当 `pluginNavigation` 可用时显示）。
  - 不提供“排序方式”：状态分组的组内顺序由任务语义决定；工作区/单列表固定为“置顶在前，其余按最近更新”，与原生默认一致。手动拖拽排序见第 9 节。
- **添加工作区**（文件夹+图标）：打开“添加工作区”对话框（原生 `Modal`）：路径输入框、“浏览…”（宿主原生目录选择器，不可用时只保留输入）、添加。
- **窄栏（rail）**：与原生一致，只显示 36px 的搜索与添加工作区按钮；搜索按钮先展开侧栏再聚焦输入框。
- **连接状态**：仅在“正在重连（显示最近状态）”或“任务服务不可达，正在重试”时，在标题行下显示一行次要文字，前置警示状态点。其余时间不占空间。
- **提示**：命令失败、重连后的补偿结果用原生 `Toast` 显示（5 秒），不再在列表上方插入横幅。

## 4. 分组方式

### 4.1 状态（默认）

| 分区 | 图标 | 组内顺序 | 默认折叠 | 水位线 |
| --- | --- | --- | --- | --- |
| 置顶 Pinned | 图钉 | 原生置顶顺序 | 展开 | 无 |
| 待处理 Active | 队列 | 关注事件时间倒序（`domain/sort.ts`） | 展开 | 有 |
| 运行中 Working | 播放 | 本轮开始时间倒序 | 展开 | 无 |
| 稍后处理 Snoozed | 闹钟 | 唤醒时间升序 | 折叠 | 有 |
| 已处理 Settled | 勾选圆 | 标记时间倒序 | 折叠 | 有 |
| 已归档（仅筛选显示归档时） | 归档 | 最近更新倒序 | 展开 | 有 |

- **空分区不显示**。全部为空时显示原生空状态（图标 +“暂无会话”；“仅显示已归档”时为“暂无已归档会话 / 查看其他会话”）。
- 分组行复刻原生工作区行：左侧图标，悬停换成折叠箭头；标题；折叠时在标题后显示条目数（次要色）。分组行没有悬停操作，也没有悬停卡片。
- 折叠状态按 `status:<分区>` 存在浏览器偏好中。折叠的分区仍显示当前会话那一行（产品规格既有要求）。
- 水位线沿用原生规则：默认显示 5 行；运行中、待交互、有新结果/失败、当前会话会自动抬高水位线（最多 50）；“展开其余 N 个会话 / 收起”。
- “仅显示已归档”时只显示已归档分区。

### 4.2 按工作区

复刻原生“按工作区”：工作区按 Host 顺序，最后是“未分组”。

- 分组行：文件夹图标（含当前会话时高亮），悬停换成折叠箭头；悬停操作为 “…”（重命名、移除工作区，插件自有菜单与对话框）和“新会话”；停留 800ms 显示悬停卡片（名称、路径、创建时间，可复制路径）。右键同 “…”。
- 默认折叠；当前会话所在工作区若没有显式折叠状态，则自动展开。状态按 `workspace:<id>` 保存。
- 组内：置顶在前，其余按最近更新倒序；水位线同上。空工作区仍显示分组行。
- Snoozed / Settled 会话保留在原位，行尾显示闹钟 / 勾选图标（悬停卡片写明返回时间或收起原因），不变灰。已归档会话按筛选显示为灰色。

### 4.3 单列表

全部会话一个列表：置顶在前，其余按最近更新倒序；无分组行、无水位线。行尾指示同 4.2。

与原生的差异（2026-11-12，Q02）：原生渲染全部行；在 5000 会话下切入单列表 p95 达 895 ms，超出实现 Spec §10 的有界窗口预算。本插件因此先渲染 200 行，滚动接近末尾时再增加 200 行，并始终包含当前会话。界面上没有“展开”按钮，观感与原生一致。

## 5. 会话行

复刻原生会话行（32px，左侧 16px 状态格，标题单行、悬停时过长标题滚动显示）：

- **状态点**（`StateDot`）：等待审批/回答/需处理/需检查 → warning；运行中 → ongoing；失败 → error；新结果 → done；空闲/未知 → 不显示。已归档行不显示。
- **静止时行尾**：待审批/待回答显示紧凑标签，否则显示相对时间（`relativeTime`，与原生同一词表）；状态分组以外再显示 Snoozed/Settled 指示图标；不在“置顶”分区时显示置顶图标。
- **悬停 / 菜单打开 / 键盘聚焦时行尾**换成操作条：
  1. “…”：打开原生会话菜单，菜单中含归档。
  2. **收起 / 取消收起**：
     - 已处理（Settled）→ 取消收起（`reopen`）。
     - 否则当 `domain/commands.settle` 对当前事实判定可行时 → 收起（`settle`）。置顶、已归档、运行中、待审批/回答、状态未同步时不显示。
     - 已归档行改为显示“取消归档”。
     - Host 未就绪（重连中）时按钮保留但禁用。
  3. **置顶 / 取消置顶**（`uiWorkspace.pinSession/unpinSession`），已归档行不显示。
- **右键 / 菜单键**：原生会话菜单。本插件在菜单中继续提供：立即返回/取消收起、稍后处理 ▸（预设 + 自定义时间…）、收起、此会话不自动收起。
- **点击 / Enter / Space**：打开会话；已归档会话提示“已归档对话暂时无法查看，请取消归档后查看”。
- **悬停卡片**（800ms，同组联动）：标题、工作目录、“N 前”，本插件的一行任务说明（“{时间} 返回”“因 N 天无活动自动收起”“已手动标记处理”“此会话不自动收起”），然后是状态行与已归档行；可复制标题。
- 当前会话行高亮（`aria-selected`）。

## 6. 搜索

复刻原生：查询非空时列表替换为扁平结果。

- 本地即时匹配：标题、工作区名、会话 ID；同时防抖 250ms 调用 `sessions.search` 做正文搜索；查询截断到 500 个 UTF-16 码元、去除 NUL。
- 结果行 48px：状态点 + 标题；下一行为工作区名与正文片段。已归档结果灰显并带“取消归档”。
- 正文搜索进行中显示骨架行；无结果显示“无匹配会话”；`hasMore` 时显示“仅显示前 N 条结果，请缩小搜索范围”。
- 结果遵循归档筛选。点击结果打开会话并清空搜索。
- 不再有“包含消息正文”开关：与原生一致，始终同时搜索标题与正文。

## 7. 设置页

在 **插件 → 已安装 → DeepSeek Harness T3 Sidebar** 详情页，通过 `plugins.bundle.config`（键 `dsh-t3code-sidebar`，`view: 'page'`）渲染：

1. **任务状态存储**：Host 存储 / 浏览器本地预览（及原因）/ 正在连接。
2. **自动收起**：开关；“无活动天数”（1–90）；“保留失败会话直到我查看”；保存按钮与结果提示。只有 Host 后端可编辑。
3. **最近的变更**：最近 20 条状态迁移（会话、从→到、原因、时间），含手动与自动。

侧栏不再有 ⚙ 面板。视图选项菜单的“侧栏设置…”通过 `pluginNavigation.openBundle('dsh-t3code-sidebar')` 打开该页。

## 8. 对话框

全部使用原生 `Modal`，由侧栏组件渲染（宽窄栏下都可用，因此从会话标题菜单发起的“自定义时间…”在侧栏收起时也能打开）：

- 稍后处理至…：日期时间输入、说明、取消/确定；校验沿用 `validateSnoozeUntil` 与 DST 空档拒绝。
- 添加工作区、重命名工作区、移除工作区（说明文件夹与会话记录保留）。

## 9. 已知差异与后续

| 项 | 说明 |
| --- | --- |
| 手动拖拽排序、按工作区树分组、拖拽调整工作区顺序 | 未移植；原生的手动顺序存于其私有 store |
| 原生行装饰子槽（`sidebar.session.row.leading/trailing/hover`、`row.action`）与目录流子槽 | 由原生注册声明，覆盖者无法渲染；其他插件的行装饰不会出现 |
| 原生工作区菜单 | 原生的工作区重命名/删除写入隐藏浏览器读取的请求，覆盖后不会出现对话框，因此工作区 “…” 使用插件自有菜单 |
| 双击标题重命名 | 原生入口是内部回调；重命名使用 “…” 菜单 |
| ⌘K / ⌘O 快捷键 | 原生处理器驱动隐藏的原生浏览器（已在 macOS 验证记录中列出），本次不变 |

## 10. 偏好迁移

浏览器偏好键仍为 `t3-sidebar:v1:prefs`：

- 新字段：`groupBy: 'status' | 'workspace' | 'flat'`（默认 `status`）、`archivedFilter: 'default' | 'show' | 'only'`。
- 旧 `view: 'projects'` 迁移为 `groupBy: 'workspace'`，其余为 `status`；旧折叠键 `tasks:<分区>` 迁移为 `status:<分区>`。
- 删除 `scope`、`includeContent`。`lastSeen` 原样保留。

## 11. 验收

- 默认进入“状态”分组；切换三种分组、三种归档筛选后刷新页面保持。
- 空分区不渲染；全部为空显示空状态。
- 悬停会话行看到 “…”、收起/取消收起、置顶；“…” 菜单含归档与本插件动作。
- 运行中、待审批、置顶、已归档会话不显示收起按钮。
- 插件详情页出现设置区，可保存自动收起策略并看到最近变更；侧栏内无设置元素。
- 窄栏只有搜索与添加工作区按钮。
- 停用插件后原生侧栏恢复；中英文、亮暗主题正常。
